# customer-behavior-analysis

## Project Overview
This project analyzes customer transactions and behavior to identify customer segments, purchase patterns, and churn risks. The analysis includes data cleaning, feature engineering, RFM analysis, K-Means clustering, churn analysis, and data visualization.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Files Included
- customer_analysis.ipynb : Complete analysis notebook
- ecommerce_customer_data_large.csv : Original dataset
- cleaned_data.csv : Cleaned dataset
- rfm_segments.csv : Customer segmentation output

## Key Findings
- Identified 4 customer segments using RFM analysis and K-Means clustering.
- Analyzed customer churn behavior.
- Evaluated product category sales and purchase trends.
- Generated actionable business recommendations.
